# 游戏战术决策相似度补充题（设计稿，尚未加入线上问卷）

## 测量范围

记录玩家感知的战术决策结构相似度，支持预先指定的相对比较。不要将其表述成客观、完整的游戏相似度，或将它当作迁移收益的因果解释。PUBG 与永劫无间的比较应限定到具体竞技模式；生存模式与回合制、PVE 模式不能混在一起。

## 一道题：三游戏比较

中文题干：

> 以 PUBG 的竞技生存模式为参照，下面哪款游戏在玩家需要做出的战术决策上更接近它？请综合考虑行动目标、位置与路线选择、资源取舍和交战时机，按这些决策在正常对局中的重要程度作判断。仅在你熟悉这三款游戏的相应模式时作答。

英文题干：

> Taking PUBG's competitive battle royale mode as the reference, which game is more similar in the tactical decisions players need to make? Consider action goals, positioning and route choices, resource trade-offs, and engagement timing, weighted by their importance in typical matches. Answer only if you are familiar with the relevant modes of all three games.

选项：永劫无间／Counter-Strike／两者差不多／至少一款不熟悉，无法判断。前两个选项随机交换位置。题干不提示预期答案，也不先告诉参与者研究者认为哪些机制相似。不给出单个片段，以免把场景相似当成游戏相似。若需要明确排除画风影响，可补一句“请依据决策需求，而非画风或题材”。不主动排除视角、操作或战斗机制，因为它们也可能影响战术决策。

当前11款游戏的评价池不包括永劫无间，不能从现有熟悉游戏勾选中推断参与者熟悉它。需要在本题额外确认三款游戏及模式的熟悉度，或保留明确的无法判断选项；不必为此把永劫视频加入意图题池。

可预注册少量比较，例如 PUBG—永劫／CS，以及 PUBG—Apex／CS。每人只抽一组符合熟悉度条件的比较；不要为了补全所有游戏关系而把几十份回答摊到55个游戏对。若只关心 PUBG 与永劫的补充讨论，先集中收集这一组。

## 回收与报告

- 规划每个核心三元比较30–50份独立、熟悉三款游戏的有效回答；这只是回收目标，不是通用显著性或合格门槛。
- 报告全部分配人数、熟悉度合格人数、两者差不多比例、无法判断比例，以及明确选择者中偏好每款游戏的比例及95% Wilson区间。
- 明确选择者的比例区间跨过50%时，不宣称玩家更倾向某款。把平局与无法判断单列，不能悄悄删除后只报有利百分比。
- 论文可写“在熟悉三款游戏的参与者中，更多人认为……的战术决策更接近……”，不能写“证明了两款游戏客观上更相似”。
- 保存题目版本、参照游戏与模式、两个候选与模式、呈现顺序、熟悉度、答案、参与者ID和时间戳。每人至多提交一次；与五段视频评价单独计数、单独统计。

## 配合的非问卷证据

可在supp中按事先定义的机制维度列事实表，例如胜利条件、是否有收缩安全区、资源获取与持续消耗、失败与重生规则、队伍结构。每项给官方规则来源；不要根据迁移结果调整维度或权重。必要时可以在公开编码规则下计算二元机制向量的Jaccard相似度，但它仅度量选定维度，不能消除特征选择的主观性。

迁移实验衡量的是指定模型、训练预算和数据分布下的可迁移性，可以与相似度假设并列讨论，不能用迁移好来定义相似、再用相似解释迁移好。Taskonomy提供了以迁移关系研究任务结构的相关先例，但不直接给出游戏机制相似度：[CVPR 2018](https://openaccess.thecvf.com/content_cvpr_2018/papers/Zamir_Taskonomy_Disentangling_Task_CVPR_2018_paper.pdf)。
